## 📖 عن التطبيق

**Ayatify** هو تطبيق إسلامي مفتوح ومجاني صُمم لتقديم تجربة استماع فاخرة لكتاب الله عز وجل على الهواتف الذكية، مستوحاة من واجهات وتجارب أحدث تطبيقات البث العالمية (مثل Spotify). يتيح التطبيق الوصول لأكثر من **244 قارئاً** بمختلف الروايات والمصاحف، مع إمكانية التحميل والاستماع دون اتصال بالإنترنت وحفظ التفضيلات سحابياً.

---

## ✨ أبرز المميزات

### 🎧 1. مشغل صوتي احترافي (Modern Audio Player)
- **تشغيل بالخلفية (Background Playback)**: يستمر الصوت بالعمل بسلاسة عند قفل الشاشة أو استخدام أي تطبيق آخر.
- **شريط تحكم متكامل في الإشعارات وشاشة القفل**: إيقاف، تشغيل، تخطي للسورة التالية أو السابقة.
- **مؤقت النوم الذكي (Sleep Timer)**: ضبط التوقف التلقائي بعد (10، 15، 30، 45، 60 دقيقة) أو فور **انتهاء السورة الحالية**.
- **التحكم بالسرعة وتخطي الوقت**: تسريع أو تبطئة القراءة (0.75x إلى 1.5x) وقفز ±10 ثوانٍ لتسهيل الحفظ والمراجعة.
- **الاستئناف التلقائي (Smart Resume)**: حفظ آخر ثانية استمعت إليها والرجوع إليها تلقائياً.
- **الانتقال السريع لصفحة الشيخ**: ضغطة واحدة على اسم القارئ في المشغل تفتح قائمة كافة سوره.

### 📥 2. تنزيل واستماع بدون إنترنت (100% Offline Mode)
- **تحميل مباشر بصيغة MP3**: حفظ أي سورة بجودتها الأصلية داخل ذاكرة الهاتف بضغطة زر.
- **مشغل تحميلات داخلي**: تشغيل التنزيلات مباشرة من تبويب "قوائم التشغيل" دون الحاجة لمدير ملفات خارجي.
- **فرز وفلترة التنزيلات**: ترتيب حسب الأحدث أو الأقدم، أو تصفية السور حسب اسم القارئ.
- **واجهة مدمجة ذاتياً**: جميع ملفات التصميم والأيقونات والخطوط مخزنة داخل التطبيق لضمان عمل الواجهة بنسبة 100% بدون نت وفي وضع الطيران.

### 🎙️ 3. مكتبة شاملة للقراء والمصاحف
- أكثر من **244 قارئاً** بمختلف الروايات (حفص عن عاصم، ورش عن نافع، قالون، الدوري، السوسي...).
- فهرس كامل لكافة سور القرآن الكريم (114 سورة) مع تفاصيل المكية والمدنية وعدد الآيات.
- محرك بحث لحظي وسريع للوصول الفوري لأي سورة أو شيخ.
- قائمة خاصة بالمفضلة لحفظ قرائك المقربين.

### 🌿 4. أجواء وقوائم استماع مخصصة (Playlists & Moods)
- تصنيفات جاهزة تحاكي ساعات يومك:
  - **التركيز والعمل**: تلاوات هادئة للإنتاجية والمذاكرة.
  - **النوم والاسترخاء**: تلاوات خاشعة لراحة النفس والسكينة.
  - **الهدوء والسكينة**: آيات تطمئن القلوب وتزيل الهموم.
- إمكانية إنشاء قوائم تشغيل مخصصة وتسميتها وإضافة السور إليها.
- خلفيات إسلامية فنية راقية.

### ☁️ 5. مزامنة سحابية وحسابات (Supabase Sync)
- إنشاء حساب شخصي وتأكيد الدخول الآمن.
- مزامنة المفضلة، وسجل الاستماع، وقوائم التشغيل عبر كافة أجهزتك.
- إمكانية الاستخدام الحر والكامل كـ "زائر" بدون تسجيل.

### 📊 6. ورد يومي وإحصائيات إيمانية
- تحديد هدف استماع يومي (مثل 15 أو 30 دقيقة).
- متابعة سلسلة الأيام المستمرة (Streaks) للتحفيز على المداومة.
- إحصائيات حول أكثر السور والقراء استماعاً.

### 🔄 7. فحص تلقائي للتحديثات (In-App Auto Update)
- تنبيه فوري وذكي داخل التطبيق بمجرد إطلاق إصدار جديد مع إمكانية التحديث بضغطة واحدة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Styling**: Tailwind CSS (Local Bundle)
- **Icons & Fonts**: FontAwesome 6 Pro, Cairo Font, Amiri Font
- **Mobile Runtime**: Capacitor 7 (Android Native Bridge)
- **Native Audio Engine**: Android Foreground Service (`QuranAudioService`) + MediaSession API
- **Cloud Database & Auth**: Supabase
- **Quran Data & Streaming**: MP3Quran.net Official REST API

## 🚀 التشغيل والتطوير المحلي (Getting Started)

### المتطلبات:
- Node.js (إصدار 18 فما فوق)
- Android Studio + Android SDK (API 34/35) + JDK 17

### خطوات التثبيت:
```bash
# 1. استنساخ المستودع
git clone https://github.com/karimmohamed0270/quran-phone-app.git
cd quran-phone-app

# 2. تثبيت الحزم
npm install

# 3. مزامنة ملفات الويب مع الأندرويد
npm run android:sync

# 4. فتح المشروع في Android Studio
npm run android:open
```

### لبناء ملف الـ APK النهائي (Release APK):
```bash
cd android
./gradlew assembleRelease
```
